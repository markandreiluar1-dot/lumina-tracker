# Lumina Command Center

A personal productivity and study command center built with React and Tailwind CSS. 

## Features

- **Dashboard & Gamification:** XP and leveling system, daily inspiration matrix (verses & vocabulary), and local weather integration.
- **Academics & Schedule:** Track courses, class schedules, and grades.
- **Study Hub & Zen Mode:** Pomodoro focus timer, minimalist dark-mode Zen view, and integrated focus lofi audio.
- **AI Tools (Coach Andrei & AI Scholar):** Interactive AI companion widget and instant study material generator (flashcards/quizzes).
- **Life Management:** Task manager, financial net-worth tracking, daily wellness protocol (hydration, sleep, hygiene), and a persistent scratchpad.

## Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons & Charts:** Lucide React, Recharts
